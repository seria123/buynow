# 📑 Electronics & Accessories Product Attributes

A reference guide for defining, organizing, and utilizing attributes in your electronics or accessories catalog.

---

## 1️⃣ What is an **Attribute**?

An **Attribute** is a feature or characteristic that describes a product and enables comparison and filtering.

<div style="background: #F3F4F6; padding: 1em; border-radius: 6px;">
<strong>Examples of Attributes:</strong>
<ul>
  <li>Color</li>
  <li>Storage Capacity</li>
  <li>RAM</li>
  <li>Screen Size</li>
  <li>Battery Capacity</li>
  <li>Processor</li>
  <li>Connectivity <span style="color: #6B7280;">(e.g. Bluetooth, WiFi, USB-C)</span></li>
  <li>Resolution</li>
  <li>Power Output</li>
</ul>
</div>

> **Tip:** Use attributes to distinguish products and to refine catalog/search filters for customers.

---

## 2️⃣ What is an **Attribute Value**?

An **Attribute Value** is the specific value given to an attribute for a product.

- Some attributes use **predefined values** (for consistency and filtering).
- Others require **manual entry** (where values are unique or variable).

<div style="display: flex; gap: 2em;">
<div style="flex: 1;">
<strong>Predefined Value Examples:</strong>
<ul>
  <li>Color → <span style="color:#0ea5e9">Black</span>, <span style="color:#f59e42">White</span>, <span style="color:#2563eb">Blue</span></li>
  <li>Storage → 64GB, 128GB, 256GB</li>
  <li>RAM → 4GB, 8GB, 16GB</li>
  <li>Connectivity → Bluetooth 5.0, Bluetooth 5.3</li>
  <li>Resolution → 1080p, 1440p, 4K</li>
</ul>
</div>
<div style="flex: 1;">
<strong>Manual Value Examples:</strong>
<ul>
  <li>Weight</li>
  <li>Dimensions</li>
  <li>Model Number</li>
  <li>Battery Capacity (if not standardized)</li>
</ul>
</div>
</div>

---

## 3️⃣ What is an **Attribute Family**?

An **Attribute Family** is a template grouping attributes that are relevant for a specific type or category of product.

> **Why use Attribute Families?**
> They ensure each product type (e.g., phone, laptop) is described only with applicable attributes — improving accuracy, admin efficiency, and the customer experience.

---

## 📋 Common Attribute Families

### 📱 Smartphone

- Color
- Storage Capacity
- RAM
- Screen Size
- Screen Type
- Battery Capacity
- Processor
- Operating System
- Camera Specs
- Connectivity (4G/5G, WiFi)
- Brand

---

### 💻 Laptop

- Processor
- RAM
- Storage (SSD/HDD)
- GPU
- Screen Size
- Resolution
- Battery Life
- Operating System
- Ports
- Weight
- Brand

---

### ⌚ Smartwatch

- Color
- Display Type
- Strap Material
- Battery Life
- Sensors (Heart Rate, SpO2, GPS)
- Water Resistance
- Connectivity (Bluetooth, WiFi)
- Brand

---

### 🔌 Power Bank

- Capacity (mAh)
- Output Ports
- Fast Charging Support
- Input Type (USB-C/Micro USB)
- Weight
- Brand

---

### 🎧 Headphones / Earbuds

- Color
- Type (In-Ear, Over-Ear, ANC)
- Battery Life
- Connectivity (Bluetooth Version)
- Driver Size
- Brand
